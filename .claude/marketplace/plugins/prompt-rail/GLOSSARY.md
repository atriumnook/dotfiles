# prompt-rail

長いセッションで、以前のターンを大量のスクロールなしに参照できるようにする Claude Code の mod。transcript の右端に、セッションのプロンプトを並べる。

## 会話(Claude Code が記録するもの)

**セッション**:
プロンプトとターンが属する1本の会話。`/clear` で新しいセッションになり、resume では同じセッションが続く。
_Avoid_: 会話、スレッド

**トランスクリプト**:
セッションの行を、Claude Code が書いた順に残した記録。rewind で捨てた枝の行も残る。
_Avoid_: ログ、履歴

**枝**:
トランスクリプトの行を、親から子へたどった1本の列。rewind で分かれ、最後の行を含む枝を「今の枝」と呼ぶ。
_Avoid_: branch(git の branch と紛れる)

**プロンプト**:
人が端末の入力欄か Remote Control から送り、モデルに届いた入力。ターンの実行中に送ったものと、モデルのターンを始める slash command(skill・custom command)を含む。
_Avoid_: 依頼、メッセージ、入力、指示

**ターン**:
1つのプロンプトから始まり、モデルが応答を終えるまでの区間。実行中に送ったプロンプトは、そのターンに加わる。
_Avoid_: やり取り、往復

**最後の応答**:
ターンの中で、モデルが最後に書いた文章。報告・提案・計画など、後から参照されることが多い。
_Avoid_: 報告、結果、回答(AskUserQuestion への回答と紛れる)

**ターンの要約**:
ターンの所要時間・ツール呼び出しの数・編集したファイル・結果(中断・API エラー)をまとめた1行。
_Avoid_: サマリー、統計

**compact**:
古い行を要約に置き換えて、モデルが読む文脈を縮めること。compact の前のプロンプトも、同じセッションに残る。

**サブエージェント**:
モデルが作業を任せた、別の会話。サブエージェントへの指示はプロンプトではない。

## 画面(Claude Code が描くもの)

**描かれた行**:
トランスクリプトの行のうち、Claude Code が画面用に描画を済ませた行。表示領域の外にあってもよい。
_Avoid_: 読み込まれた行、mount された行

**見えている行**:
描かれた行のうち、今ターミナルの表示領域に入っている行。

**帯**:
入力欄の上の領域。複数の mod と Claude Code が分け合って描く。
_Avoid_: band、AbovePrompt

## レール(prompt-rail が描くもの)

**レール**:
prompt-rail が transcript の右端の1列に描く、プロンプトごとの tick の列。
_Avoid_: Preview Rail(元にした beUI の部品の名前)、ミニマップ

**tick**:
レールで1つのプロンプトを表す、`━` の1文字。古い順に上から等間隔に並び、最新が一番下に来る。行数より多いプロンプトは同じ行にまとめ、`≡` で表す。
_Avoid_: 目盛り、ドット

**カード**:
tick に pointer を乗せている間だけ、その左に出す、プロンプトの本文とターンの要約。
_Avoid_: プレビュー、ツールチップ

**読んでいる位置**:
見えている行のうち一番古いプロンプト。見えている行にプロンプトが無ければ、一番古い行が属するプロンプト。
_Avoid_: 現在地、current

**見えている範囲**:
見えている行が属するプロンプトの、最初から最後まで。

**参照**:
以前のターンのプロンプトか最後の応答を読むこと。レールでジャンプし、画面で読む。
_Avoid_: 振り返り、閲覧

**ジャンプ**:
tick を押して、そのプロンプトの行が画面の上端に来るまでトランスクリプトをスクロールさせること。
_Avoid_: 移動(スクロール全般と紛れる)

**着地**:
ジャンプで、目標の行が画面の上端に来たこと。
