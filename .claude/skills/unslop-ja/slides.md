# スライド・発表資料の観点

SKILL.md の規則に加えて当てる。番号は SKILL.md と同じ固定 ID の体系に属する。

レイアウトに関する規則（S1・S2・S5）は、画像・PDF・スライドファイルなど見た目が分かる入力でのみ判定する。テキストだけを受け取った場合は、該当する規則を「未検証」と明記する。

見出し、ラベルと値（「第1段階: 社内向けアプリ（11月）」）、体言止めの箇条書きはスライドの通常の書き方なので、形式だけを理由に指摘しない。ただし SKILL.md の規則 17（コピー調の体言止め）の形は対象とする。情報が足りるかどうかは、そのページ単体ではなく資料全体で判断する。

S1. **説明上の理由がないレイアウト。** 図形や文字の位置が情報同士の関係を表しておらず、装飾になっている。
S2. **同じレイアウトの機械的な繰り返し。** 内容が違うページに同じ配置を当てはめている。
S3. **目的に合わない全体の流れ。** 説明の目的から見て、ページの順序に理由がない。
S4. **フレームワークの当てはめ。** 3C・SWOT などを、必要な箇所以外にも当てはめている。
S5. **装飾による内容不足の隠蔽。** 見出し・数字・図形を取り除くと、主張を説明できなくなる。
